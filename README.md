# 💰 Gestor Financeiro PRO

Um sistema Web completo (SaaS) para gestão financeira pessoal, com banco de dados em nuvem, autenticação de usuários e painel de indicadores dinâmicos. 

Desenvolvido para ser 100% responsivo, oferecendo uma experiência de aplicativo nativo (PWA) tanto no desktop quanto no celular.

▶️ **[Acesse o sistema online aqui](https://klebolt.github.io/Gestor_financeiro/)**

---

## ✨ Funcionalidades

- **Autenticação Segura:** Sistema de Login, Cadastro e Recuperação de Senha automatizada via e-mail.
- **Banco de Dados em Nuvem:** Dados salvos em tempo real utilizando Supabase, com segurança RLS (Row Level Security) que isola as informações de cada usuário.
- **Receitas e Despesas:** Controle completo de fluxo de caixa, calculando o saldo líquido do mês.
- **Gráficos Inteligentes:** Dashboards visuais criados com Chart.js que se adaptam automaticamente a novas categorias.
- **Dark Mode:** Tema escuro integrado com salvamento de preferência na memória local (LocalStorage).
- **Notificações Premium:** Feedbacks visuais elegantes e modais de confirmação usando SweetAlert2.
- **Parcelamento Automático:** Motor inteligente que projeta gastos futuros e vira o ano automaticamente.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3 avançado (CSS Grid, Flexbox, Variáveis nativas) e JavaScript Vanilla (ES6+).
- **Back-end / BaaS:** [Supabase](https://supabase.com/) (PostgreSQL + Auth).
- **Bibliotecas Gráficas:** - [Chart.js](https://www.chartjs.org/) (Evolução de gastos e distribuição de categorias).
  - [SweetAlert2](https://sweetalert2.github.io/) (Alertas e Toasts interativos).
- **Deploy:** GitHub Pages.

---

## 📱 Interface Responsiva

A interface foi construída com a abordagem *Mobile-First*. No celular, as tabelas tradicionais se transformam em *Cards* perfeitamente alinhados para evitar rolagem horizontal, enquanto botões e filtros são redimensionados para o toque (Touch-friendly).
